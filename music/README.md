# Approved BGM

Put only music you own or have explicit permission to use in YouTube Shorts in
this folder. The permission must also allow storing the file in GitHub and
including it in a video saved to Google Drive. For each file, add an entry to
`playlist.json` documenting the track title, source, applicable license, proof
of permission, `youtubeShortsAllowed: true`, `repositoryStorageAllowed: true`,
`driveStorageAllowed: true`, and any required attribution.

Do not assume that a public GitHub URL or a music license grants permission to
include a track in a video. Keep any license or permission evidence in a form
that can be stored in this private repository. Avoid committing confidential
correspondence or other personal information.

The workflow will not render a BGM track unless its playlist entry confirms
the required permissions and its music file exists. Reels can be rendered
without BGM.
