# Approved BGM

Put only music you own or have explicit permission to use in Instagram Reels in
this folder. The permission must also allow storing the file in GitHub,
uploading it to Cloudflare R2, and delivering it with the Reel. For each file,
add an entry to `playlist.json` documenting the track title, source, applicable
license, proof of permission, all three permissions, and any required
attribution.

Do not assume that a public GitHub URL or a YouTube-only music license permits
reposting on Instagram. Keep any license or permission evidence in a form that
can be stored and redistributed in this private repository. Avoid committing
confidential correspondence or other personal information.

Scheduled publishing fails closed unless there is at least one approved,
Instagram-cleared entry with repository-storage and hosted-delivery permission,
and its music file exists. Preview renders can be created without BGM.
